
# Виправлення регіону PostHog

## Проблема
Код відправляє аналітику на EU сервер, а ваш акаунт на US сервері.

## Рішення

### Файл 1: `src/providers/PostHogProvider.tsx`

Змінити рядок 7:
```tsx
// Було:
api_host: 'https://eu.i.posthog.com',

// Стане:
api_host: 'https://us.i.posthog.com',
```

### Файл 2: `docs/ANALYTICS.md`

Оновити документацію (рядок 9):
```markdown
// Було:
- Хост: `https://eu.i.posthog.com`

// Стане:
- Хост: `https://us.i.posthog.com`
```

## Після виправлення

1. Зміни застосуються автоматично в preview
2. **Опублікуйте** проект щоб зміни з'явились на `lystosyk.com`
3. Відвідувачі з будь-якої країни (Україна, Європа, США) будуть відстежуватись
4. Дані з'являться у вашому дашборді `us.posthog.com`

## Важливо
- Попередні дані з EU сервера не переносяться
- Нова аналітика почнеться одразу після публікації
