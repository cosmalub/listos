

# Плавный переход розового градиента в белый (до второй секции)

## Текущее состояние
- **HeroSection** (строка 19): `bg-gradient-to-b from-[#FFD1DC] via-white/50 to-white`
- **PainSection** (строка 29): `bg-[#FAFAFA]` — светло-серый

Сейчас градиент заканчивается слишком резко, и переход между секциями не плавный.

## Решение
Изменить градиент Hero-секции так, чтобы розовый держался дольше, а переход в белый был более растянутым и мягким. Также убрать padding снизу у Hero и добавить отрицательный margin сверху у PainSection для визуального "перетекания".

## Изменения

### 1. HeroSection.tsx (строка 19)
Удлинить розовую часть градиента, убрать нижний padding:

```tsx
// Было:
<section className="relative min-h-[90vh] flex items-center justify-center overflow-hidden pt-40 pb-16 px-4 bg-gradient-to-b from-[#FFD1DC] via-white/50 to-white">

// Станет:
<section className="relative min-h-[90vh] flex items-center justify-center overflow-hidden pt-40 pb-32 px-4 bg-gradient-to-b from-[#FFD1DC] from-30% via-[#FFE4E9] via-60% to-white">
```

**Что изменится:**
- `from-30%` — розовый держится первые 30% высоты секции
- `via-[#FFE4E9]` — промежуточный мягкий розовый (вместо white/50)
- `via-60%` — переход начинается на 60%
- `pb-32` — больше пространства снизу для плавного перехода

### 2. PainSection.tsx (строка 29)
Добавить верхний градиент для "подхвата" розового и плавного перехода:

```tsx
// Было:
<section className="relative py-32 bg-[#FAFAFA] overflow-hidden">

// Станет:
<section className="relative py-32 bg-gradient-to-b from-white via-white to-[#FAFAFA] overflow-hidden">
```

**Что изменится:**
- Верх PainSection начинается с белого (как заканчивается Hero)
- Плавно переходит в `#FAFAFA`
- Визуально секции "сливаются" в один плавный поток
