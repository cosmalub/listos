
# Редизайн PainSection: Компактні картки з іконками

## Поточний стан
Секція займає ~120vh (3 блоки по 40vh) зі scroll-анімацією, яка може бути непомітною при швидкому скролі.

## Новий дизайн
Компактна сітка 2×2 карток з іконками — зрозуміло, швидко сканується, займає менше місця.

## Зміни

### PainSection.tsx — повна заміна

**Структура:**
- Секція з м'яким градієнтом (як зараз)
- Заголовок секції
- Сітка 2×2 (на мобільному — 1 колонка)
- 4 картки з іконками (Lucide)

**Іконки:**
| Біль | Іконка |
|------|--------|
| "Я тебе люблю" занадто просто | `HeartCrack` |
| Квіти — гарно, але порожньо | `Flower2` |
| Повідомлення зникне завтра | `MessageCircle` |
| Слова застрягають усередині | `MicOff` |

**Стиль карток:**
- Білий фон з легкою тінню
- Рожевий/фіолетовий акцент на іконці
- Плавна анімація появи при скролі (stagger)
- Hover-ефект — легке підняття

**Код картки:**
```tsx
<motion.div className="bg-white p-6 rounded-2xl shadow-sm border border-gray-100 hover:shadow-md hover:-translate-y-1 transition-all">
  <div className="w-12 h-12 rounded-xl bg-rose-50 flex items-center justify-center mb-4">
    <HeartCrack className="w-6 h-6 text-rose-500" />
  </div>
  <p className="text-gray-800 font-medium">
    "Я тебе люблю" <span className="text-gray-400 font-normal">звучить занадто просто</span>
  </p>
</motion.div>
```

## Технічні деталі

| Аспект | Значення |
|--------|----------|
| Висота секції | ~50-60vh (замість ~120vh) |
| Анімація | Fade-in + stagger (0.1s між картками) |
| Responsive | 1 колонка на мобільному, 2 на md+ |
| Іконки | Lucide React (HeartCrack, Flower2, MessageCircle, MicOff) |

## Результат
- Секція стає компактнішою
- Інформація сканується за 2-3 секунди
- Іконки додають візуальний інтерес
- Плавний перехід з Hero секції (білий фон)
