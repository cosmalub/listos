

# Исправление анимации текста в PainSection

## Текущая проблема
Сейчас анимация работает так:
- Текст появляется **снизу** (y: 60 → 0)
- Исчезает **вверх** (y: 0 → -40)
- Следующий текст снова появляется **снизу**

Это создаёт визуальный разрыв — текст "прыгает" в разных направлениях.

## Решение: Простой fade без вертикального движения

Убрать `y` transform полностью. Текст будет плавно появляться и исчезать **на месте** — это чище и логичнее.

## Изменения в файле `src/components/valentine-new/PainSection.tsx`

### Строки 11-14 — упростить анимацию

```tsx
// Было:
const opacity = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [0, 1, 1, 0]);
const scale = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [0.9, 1, 1, 0.95]);
const y = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [60, 0, 0, -40]);

// Станет:
const opacity = useTransform(scrollYProgress, [0, 0.4, 0.6, 1], [0, 1, 1, 0]);
const scale = useTransform(scrollYProgress, [0, 0.4, 0.6, 1], [0.95, 1, 1, 0.95]);
// Убираем y-transform — текст остаётся на месте
```

### Строка 19 — убрать `y` из style

```tsx
// Было:
style={{ opacity, scale, y }}

// Станет:
style={{ opacity, scale }}
```

## Результат

| До | После |
|----|-------|
| Текст появляется снизу → уходит вверх → следующий снизу | Текст плавно появляется и исчезает на месте |
| Визуальный "скачок" между фразами | Плавная смена фраз |
| Запутанное движение | Чистый, понятный эффект |

## Альтернатива (если хочется движение)

Можно сделать так, чтобы все двигалось **только вверх** — более логичный поток при скролле вниз:

```tsx
const y = useTransform(scrollYProgress, [0, 0.4, 0.6, 1], [30, 0, 0, -30]);
```

Но рекомендую начать с простого fade — он выглядит чище.
