

# Исправить Hero-секцию /valentine-new — убрать розовое пятно

## Проблема
SVG-сердце (строки 45-57) имеет заливку `text-rose-100` — это создаёт огромную розовую фигуру 850x850px поверх фона. Фон секции не виден, потому что сердце его перекрывает.

## Решение
Сделать сердце **контурным** (только обводка) вместо залитого. Это создаст лёгкий романтичный контур без "пятна".

## Изменения в `src/components/valentine-new/HeroSection.tsx`

### 1. Сердце — сделать контурным (строки 45-57)
**Было:**
```tsx
<motion.svg
  viewBox="0 0 512 512"
  className="w-[850px] h-[850px] text-rose-100"
  ...
>
  <path
    fill="currentColor"
    d="M462.3 62.6C407.5..."
  />
</motion.svg>
```

**Станет:**
```tsx
<motion.svg
  viewBox="0 0 512 512"
  className="w-[850px] h-[850px]"
  ...
>
  <path
    fill="none"
    stroke="#fecdd3"
    strokeWidth="3"
    d="M462.3 62.6C407.5..."
  />
</motion.svg>
```

### 2. Glass overlay — тоже контурным (строки 60-79)
**Было:**
```tsx
<path
  fill="url(#glassGradient)"
  fillOpacity="0.3"
  ...
/>
```

**Станет:**
```tsx
<path
  fill="none"
  stroke="rgba(255,255,255,0.4)"
  strokeWidth="2"
  ...
/>
```

### 3. Фон секции — мягкий розовый градиент на ВСЮ секцию (строка 19)
Уже сделан: `bg-gradient-to-b from-pink-50/80 via-white to-white` — теперь будет виден!
