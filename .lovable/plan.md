

# Красивый переход Hero → Pain с анимацией текста при скролле

## Идея дизайна

1. **Плавный переход** — добавить градиентный "разделитель" между секциями
2. **Текст появляется по одной фразе** — когда скроллишь, фраза плавно появляется в центре экрана, потом исчезает, появляется следующая
3. **Sticky-эффект** — текст "приклеивается" к экрану пока читаешь, потом уходит

## Технические изменения

### 1. HeroSection.tsx — добавить градиентный "хвост"
Добавим декоративный градиент снизу секции, который плавно переходит в следующую.

```tsx
// В конце секции, перед </section>
<div className="absolute bottom-0 left-0 right-0 h-32 bg-gradient-to-b from-transparent to-rose-50/30 pointer-events-none" />
```

### 2. PainSection.tsx — полный редизайн анимации

**Новая структура:**
- `position: sticky` для контейнера с текстом
- Каждая фраза появляется по очереди при скролле
- Более плавные переходы opacity и scale
- Уменьшенная высота секции (сейчас слишком растянуто)

```tsx
// Новый PainPoint компонент:
const PainPoint = ({ text, index }: { text: React.ReactNode, index: number }) => {
  const ref = useRef(null);
  const { scrollYProgress } = useScroll({
    target: ref,
    offset: ["start end", "center center"] // Появляется когда доходит до центра
  });

  // Более плавная анимация: 0→1→0
  const opacity = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [0, 1, 1, 0]);
  const scale = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [0.9, 1, 1, 0.95]);
  const y = useTransform(scrollYProgress, [0, 0.3, 0.7, 1], [60, 0, 0, -40]);

  return (
    <motion.div
      ref={ref}
      style={{ opacity, scale, y }}
      className="h-[70vh] flex items-center justify-center px-8 sticky top-0"
    >
      <h3 className="text-3xl md:text-5xl lg:text-6xl font-bold text-gray-900 text-center leading-tight max-w-3xl">
        {text}
      </h3>
    </motion.div>
  );
};
```

**Обновленная секция:**
- Верхний градиент для "подхвата" от Hero
- Убрать заголовок "Чому звичайного недостатньо" (текст сам за себя говорит)
- Мягкие фоновые пятна для атмосферы

### 3. Визуальный переход между секциями

Добавим "мост" между Hero и Pain — мягкие размытые круги:

```tsx
// В начале PainSection
<div className="absolute -top-20 left-1/2 -translate-x-1/2 w-[600px] h-[200px] 
                bg-gradient-radial from-rose-100/60 via-purple-50/40 to-transparent 
                blur-3xl pointer-events-none" />
```

## Результат
- Плавный визуальный переход между секциями
- Текст появляется по одной фразе при скролле
- Фраза "держится" в центре экрана пока читаешь
- Потом плавно исчезает и появляется следующая
- Чистый, минималистичный дизайн без лишних элементов
