

# Заміна контенту TrustSection на "Ми гарантуємо"

## Що зробимо
Візьмемо текстовий контент з блоку "Ми гарантуємо" на головній та адаптуємо його для Valentine сторінки, зберігаючи стилістику (сірі заголовки, фіолетові акценти).

## Контент для перенесення

**З головної (guarantee-section.tsx):**
- Заголовок: "Ми гарантуємо"
- Підзаголовок: "Ти отримаєш листівку, яку приємно вручити. Якщо результат не сподобається — ми повернемо гроші протягом 24 годин."
- CTA блок: "Можеш почати без ризику" + "Якщо щось піде не так — ми повернемо гроші."

## Структура нового TrustSection

```text
┌─────────────────────────────────────────────────────┐
│  Ми гарантуємо                                      │  ← заголовок
│  Ти отримаєш листівку, яку приємно вручити...       │  ← підзаголовок
├─────────────────────────────────────────────────────┤
│  ┌───────────┐  ┌───────────┐                       │
│  │ ✓ Не треба│  │ ✓ Немож-  │                       │  ← 4 картки
│  │   вміти   │  │   ливо    │                       │    (залишаємо
│  │   писати  │  │   погано  │                       │     існуючі)
│  └───────────┘  └───────────┘                       │
├─────────────────────────────────────────────────────┤
│  ╔═══════════════════════════════════════════════╗  │
│  ║  Можеш почати без ризику                      ║  │  ← фіолетовий
│  ║  Якщо щось піде не так — повернемо гроші      ║  │    CTA блок
│  ║                                               ║  │
│  ║        [ Почати без ризику ]                  ║  │
│  ╚═══════════════════════════════════════════════╝  │
└─────────────────────────────────────────────────────┘
```

## Зміни у файлі `src/components/valentine/TrustSection.tsx`

### 1. Заголовок та підзаголовок
```tsx
// Було:
<h2>Зняття страхів</h2>
<p>Ми подбали про все, щоб тобі було легко і впевнено</p>

// Стане:
<h2>Ми гарантуємо</h2>
<p>Ти отримаєш листівку, яку приємно вручити.
   Якщо результат не сподобається — ми повернемо гроші протягом 24 годин.</p>
```

### 2. Фінальний блок (замість "Твій ризик — нуль")
Додамо CTA блок у стилі Valentine з кнопкою:
```tsx
// Було: простий градієнтний блок з текстом

// Стане: фіолетовий CTA блок з кнопкою
<div className="bg-gradient-to-br from-[#6B5CE7] to-[#8A7AEE] rounded-3xl p-8 md:p-12 text-white shadow-xl">
  <h3>Можеш почати без ризику</h3>
  <p>Якщо щось піде не так — ми повернемо гроші.</p>
  <Button>Почати без ризику</Button>
</div>
```

### 3. Додати імпорти
```tsx
import { Button } from "@/components/ui/button";
import { useOrderDialog } from "@/components/order/OrderDialogContext";
```

## Стилістична адаптація

| Елемент | Головна | Valentine |
|---------|---------|-----------|
| Заголовок | `text-[#6A5ACD]` | `text-gray-900` |
| Підзаголовок | `text-[#6A5ACD]/80` | `text-gray-600` |
| CTA фон | `from-[#6A5ACD] to-[#8A7AEE]` | `from-[#6B5CE7] to-[#8A7AEE]` |
| Кнопка | білий фон, фіолетовий текст | білий фон, фіолетовий текст |

## Що залишаємо без змін
- 4 картки з галочками (вони добре вписуються в концепцію гарантій)
- Загальна структура секції
- Стилі карток (border-purple-100)

## Технічні деталі
- Додаємо `useOrderDialog` hook для кнопки
- Кнопка відкриває діалог замовлення з trackingSource 'guarantee-valentine'

## Результат
- Секція тепер акцентує на гарантії повернення грошей
- Є чіткий CTA "Почати без ризику"
- Стилістика узгоджена з іншими секціями Valentine
